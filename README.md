## Introduction

This app was created to try implementing a Particle Life application in Unity with GPU optimizations for the best performance.

## Building and editing

Application was created using: [Unity 6000.3.10f1](https://unity.com/releases/editor/whats-new/6000.3.10f1).
You will need to download it if you want to edit the project.

### 1. Clone the project:

```bash
git clone git@github.com:Kminek2/Particle-life.git
```

### 2. Open it inside Unity

Opened cloned project using Unity.
